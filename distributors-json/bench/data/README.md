# Benchmark data

These JSON documents are copied from [aeson](https://github.com/haskell/aeson)'s
benchmarks (`benchmarks/json-data`, aeson 2.2.5.1), which are distributed under
aeson's BSD-3-Clause license:

> Copyright (c) 2011, MailRank, Inc. 2014-2021 Aeson project contributors.
> All rights reserved.

- `twitter10.json`, `twitter100.json`: Twitter search results, 10 & 100 stories.
- `jp100.json`: Twitter search results of Japanese text, 100 stories.
- `github-issues.json`: 30 issues of a GitHub repository, by GitHub's API.
- `geometry.json`: a GeoJSON polygon.
- `buffer-builder.json`: 96 generated records of people.
