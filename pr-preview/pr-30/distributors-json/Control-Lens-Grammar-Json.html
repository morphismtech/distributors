Description

A Json grammar of a type parses, prints & encodes its JSON, compatibly with aeson, & types it in TypeScript, all at once.

Deriving

A Generic type derives its grammar, by aeson's default options.

>>> :{
data Person = Person {name :: Text, age :: Int, email :: Maybe Text}
  deriving stock (Show, Generic)
  deriving anyclass Json
:}

>>> LByteString.putStrLn (encodingToLazyByteString (jsonEncode (Person "Ada" 36 Nothing)))
{"name":"Ada","age":36,"email":null}
>>> jsonDecode @Person "{\"name\":\"Ada\",\"age\":36}"
Right (Person {name = "Ada", age = 36, email = Nothing})

Failures are located, & name what they expected.

>>> either explain show (jsonDecode @Person "{\"name\":\"Ada\",\"age\":\"36\"}")
"Error in $.age: expected Int, but found \"36\""

aeson

ViaJson derives aeson's instances, & jsonGeneric takes aeson's Options.

>>> :{
data Pet = Cat | Dog
  deriving stock (Show, Generic)
  deriving (Aeson.ToJSON, Aeson.FromJSON) via ViaJson Pet
instance Json Pet where
  json = jsonGeneric Aeson.defaultOptions {Aeson.constructorTagModifier = map toLower}
:}

>>> Aeson.encode [Cat, Dog]
"[\"cat\",\"dog\"]"

Grammars

A grammar is written once, with the combinators of JsonVal, JsonObj, JsonTup & JsonStr, & jsonTyped names its type.

>>> :{
data Point = Point Double Double
  deriving stock Show
instance Json Point where
  json = jsonTyped $ iso (\(Point x y) -> (x, y)) (uncurry Point)
    >~ jsonObject ("x" !: json >*< "y" ?: json != 0)
:}

>>> jsonDecode @Point "{\"x\":1}"
Right (Point 1.0 0.0)
>>> jsonPrint (Point 1 0)
Object (fromList [("x",Number 1.0)])

A tuple is an array of elements, & a sum is the alternative grammars of its constructors, here tagged by string literals.

>>> :{
data Shape = Circle Double | Rectangle Double Double
  deriving stock Show
_Circle :: Prism' Shape Double
_Circle = prism' Circle (\case Circle r -> Just r; _ -> Nothing)
_Rectangle :: Prism' Shape (Double, Double)
_Rectangle = prism' (uncurry Rectangle) (\case Rectangle w h -> Just (w, h); _ -> Nothing)
instance Json Shape where
  json = jsonTyped $ orP
    [ _Circle >? jsonObject ("kind" !: "circle" >* "radius" !: json)
    , _Rectangle >? jsonObject ("kind" !: "rectangle" >* "size" !: jsonTuple (jsonElem json >*< jsonElem json))
    ]
:}

>>> LByteString.putStrLn (encodingToLazyByteString (jsonEncode [Circle 1, Rectangle 2 3]))
[{"kind":"circle","radius":1.0},{"kind":"rectangle","size":[2.0,3.0]}]

Json

class Json a where Source #

A type with a JSON grammar, like aeson's ToJSON & FromJSON together, which every JsonVal interprets. Its methods default to aeson's defaults, & json to the Generic grammar, by aeson's default options.

jsonList :: JsonVal p => p [a] [a] Source #

toJSONList & parseJSONList, as one grammar, an array of values by default. Char and wrappers override it, so that a String is a JSON string.

jsonKey :: Maybe (forall (k :: Type -> Type -> Type). JsonStr k => k a a) Source #

toJSONKey & parseJSONKey as one grammar for the text keys of objects, or else Nothing for the keys of arrays of pairs.

jsonKeyList :: Maybe (forall (k :: Type -> Type -> Type). JsonStr k => k [a] [a]) Source #

toJSONKeyList & parseJSONKeyList as one grammar for keys of lists, like jsonList. Char and wrappers override it.

jsonOmitField :: Maybe (APrism' a ()) Source #

omitField & omittedField together, as the value of a record's field which may be omitted, like nearly: it matches the value omitted by omitNothingFields, & reviews the value of a field omitted by allowOmittedFields.

class (CocartesianChoice p, Filtrator p, JsonStr p) => JsonVal (p :: Type -> Type -> Type) where Source #

JsonVal grammars describe JSON values: null, booleans, numbers, strings, by JsonStr, arrays & objects, by JsonTup & JsonObj. As CocartesianChoices & Filtrators, they have alternatives (>+<, >|<) & partial isomorphisms (>?, ?<). Its numbers are bounded, & its integers integral, as aeson's are.

jsonDict :: (forall (k :: Type -> Type -> Type). JsonStr k => k a b) -> p c d -> q [(a, c)] [(b, d)] Source #

The properties of an object which aren't named by !: or ?:, as a list of key-value pairs, by a grammar of keys & a grammar of values.

On its own, it's a dictionary.

jsonObject (jsonDict jsonText json)
-- {"a": 1, "b": 2}  <->  [("a", 1), ("b", 2)]

Beside named properties, it's the rest of them.

jsonObject ("id" !: json >*< jsonDict jsonText json)
-- {"id": 1, "a": true, "b": false}  <->  (1, [("a", True), ("b", False)])

Parsing fails unless every remaining property matches both grammars, so a narrower key grammar than jsonText, like jsonEnumWith, restricts the keys allowed. Printing fails on a key which repeats, or which is also named. An object has at most one jsonDict.

In TypeScript, it's an index signature, { [key: string]: T }, or, of an enumeration of keys, a mapped type, { [key in K]?: T }.

data JsonError Source #

A located failure to decode, parse or print a Value. Its path is relative to that Value, root first. It expected one of the alternatives, none meaning just "unexpected". Parsing found a Value, or decoding found text which isn't JSON, by aeson's message; printing doesn't show the Haskell value it found. It failed within rules, outermost first, branching where alternatives failed alike; a rule it failed for as a whole is its expectation instead.
