TokenAlgebra

class Tokenized token p => TokenAlgebra token p where Source #

TokenAlgebra extends Tokenized methods to support BooleanAlgebra operations within a tokenClass. When a TokenAlgebra is a DisjunctiveMonoid, then tokenClass is expected to act homomorphically on disjunction.

prop> falseP = tokenClass falseP
prop> tokenClass x >|< tokenClass y = tokenClass (x >|< y)

Likewise, when a TokenAlgebra is Alternative,

prop> empty = tokenClass falseP
prop> tokenClass x <|> tokenClass y = tokenClass (x >|< y)

RegEx & TokenClass

data RegEx token Source #

The RegExpression type forms the prototypical KleeneStarAlgebra. It is also a TokenAlgebra and tokenClass acts homomorphically on disjunction. RegExpressions may be understood as normalizations of KleeneStarAlgebra expressions generated by lexical token expressions.

newtype TokenClass token Source #

TokenClass forms a Tokenized BooleanAlgebra, such that the following invariants hold.

prop> trueP = anyToken
prop> trueP = notOneOf []
prop> falseP = oneOf []
prop> notP . oneOf = notOneOf
prop> notP . notOneOf = oneOf
prop> notP . asIn = notAsIn
prop> notP . notAsIn = asIn

TokenClass is the fixed point algebra of RegExam. tTokenClasses may be understood as normalizations of BooleanAlgebra expressions generated by Tokenized expressions.
