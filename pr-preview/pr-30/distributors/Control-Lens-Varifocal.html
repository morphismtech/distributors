Varifocal

type Varifocal s t a b = forall (p :: (Type -> Type) -> Type -> Type -> Type) (m :: Type -> Type). (MonadicTrans p, Alternator (p m), MonadPlus m, Filterable m) => p m a (m b) -> p m s (m t) Source #

Varifocals are context-sensitive bidirectional parser optics, whose shape may depend on the foci they build, as varifocal lenses refocus by what they're looking at. Their Applicative is the monad m of a MonadicTrans profunctor, whose effects it absorbs by joinP, so failure & choice backwards have a home, rather than needing flattening.

Bifocal ⊂ Varifocal,

instantiating a Bifocal's p & f as p m & m, so every Prism, Prismoid & Bifocal is a Varifocal too, composing with them by (.).

Unlike them, a Varifocal needs a MonadicTrans profunctor, like a Data.Profunctor.Grammar.Printor or Parsor, so static ones, like a Data.Profunctor.Grammar.Grammor, can't run it. Nor can a Data.Profunctor.Grammar.Parsector.Parsector, by design: its failure backtracks by its state, which a Varifocal's failure, by its monad's mzero, can't reach, & its backtracking can't undo a monad's effects.

type Varifocal' s a = Varifocal s s a a Source #

A simple Varifocal.

type AVarifocal s t a b = Varifocus a b [] a [b] -> Varifocus a b [] s [t] Source #

AVarifocal is monomorphically a Varifocal, at the free Varifocus, whose monad is the list monad, which embeds into every MonadPlus.

prop> Varifocal s t a b ⊂ AVarifocal s t a b

data Varifocus a b (m :: Type -> Type) s t where Source #

A Varifocus is the concrete form of a Varifocal, a free MonadicTrans Alternator on one FocusP: its syntax, with a constructor for each method which can't be derived, & for each one which a target may override, like manyP, so that running it, by runVarifocus, keeps the target's own. Its Filterable, Cochoice & Filtrator derive from its Monad & Alternative, by mfiltrate.

contextually :: (Monadic p, Alternator p) => AVarifocal s t a b -> p a b -> p s t Source #

Action of AVarifocal on Monadic Alternators, like a Control.Lens.Grammar.CtxGrammar's, by its Varifocus, whose choices & failures are the Alternator's own, so that it backtracks as the Alternator does.

prop> contextually vari = runVarifocus (varifocus vari)

contextuallyT :: forall p (m :: Type -> Type) s t a b. (MonadicTrans p, Alternator (p m), MonadPlus m, Filterable m) => Varifocal s t a b -> p m a b -> p m s t Source #

Action of a Varifocal on MonadicTrans Alternators, absorbing its monad by joinP, applying it directly.

prop> contextuallyT vari p = joinP (vari (rmap pure p))

stepping :: st -> (st -> a -> Either Bool st) -> Varifocal' [a] a Source #

Foci stepped through by a deterministic machine, from a state, deciding by each focus built whether to continue, Right state, to stop there, Left True, or to reject, Left False, as no Bifocal can. A list matches when its last focus, & no earlier one, stops it.

terminatedBy :: (a -> Bool) -> Varifocal' [a] a Source #

Zero or more foci, then one which ends them, deciding by each focus built, like a sentinel-terminated sequence, a C string's. A list which doesn't end by its first ending focus doesn't match.

prop> terminatedBy end = stepping () (\() -> bool (Right ()) (Left True) . end)

delimited :: (a -> a -> Bool) -> Varifocal' [a] a Source #

Foci opened by the first, & closed by the first after it which matches it, deciding by the opening focus built, like a heredoc's tag, or a fenced code block's fence, whose language, of matching delimiters, isn't context-free. A list which doesn't close by its first match doesn't match.

balanced :: (a -> Bool) -> (a -> Bool) -> Varifocal' [a] a Source #

Foci opened by one which opens, & closed by the one which closes, at the same nesting depth, like nested comments, * * * *, or a balanced block, whose language, of nested pairs, isn't regular. A focus may not both open & close. A list which doesn't open first, or close only last, doesn't match.

countPrefixed :: (a -> Int) -> Varifocal' [a] a Source #

A focus counting how many foci follow it, then those, like a length-prefixed record of bytes in a binary format. A list which doesn't have as many as its first focus counts doesn't match.
