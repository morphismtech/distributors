Prismoid

type Prismoid s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Alternator p, Applicative f) => p a (f b) -> p s (f t) Source #

Prismoids generalize Prisms & Diopters, combining them, matching partially forwards, into a Homogeneous shape, & building totally backwards. Writing ⊂ for "every one is a",

Prism ∪ Diopter ⊂ Prismoid ⊂ Bifocal.

A Prismoid fails by its Alternator, never by its Applicative f, so a Prism, as a Prismoid, fails on a mismatch, rather than passing it through, by the laws of CocartesianChoice, as clonePartialIso makes it do in any Choice. A Bifocal adds failing backwards, by a Filterable f.

Prismoids are isomorphic to Prismatoids.

type APrismoid s t a b = Prismatoid a b a (Identity b) -> Prismatoid a b s (Identity t) Source #

APrismoid is monomorphically a Prismoid.

data Prismatoid a b s t where Source #

A Prismatoid provides efficient access to the pair of functions that make up a Prismoid, like a Dioptrice which may fail to match.

Plasmoid

type Plasmoid s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Alternator p, Applicative f) => SepBy (p () ()) -> p a (f b) -> p s (f t) Source #

A Plasmoid is a family of optics, separated by a SepBy, which is an optic at the Alternator p of its separators.

Its separators are data-free, p () (), so they place effects between its foci, but never change what its source or target holds. So without separators, by noSep, which is polymorphic in p, a Plasmoid is a Prismoid, & its data is that Prismoid's; for any plasmoid :: Plasmoid s t a b, plasmoid noSep :: Prismoid s t a b.

>>> withPrismoid (severaled1 noSep :: Prismoid String String Char Char) $ \f _ -> fmap length (f "abc")
Just 3

operated :: (Alternator p, Applicative f) => [[Operator p a b]] -> p a (f b) -> p a (f b) Source #

An expression of Operators, from a table of them, ordered from highest to lowest precedence, like withOperators. An operator table, like a SepBy, is of an Alternator p, its symbols data-free.

>>> :{
data Sum = Digit Int | Plus Sum Sum deriving Show
_Plus :: Prism' Sum (Sum, Sum)
_Plus = prism' (uncurry Plus) (\case Plus x y -> Just (x, y); _ -> Nothing)
:}

>>> let plus = Infix LeftAssoc _Plus (Joker (() <$ char '+'))
>>> let digit = Joker (Identity . Digit . digitToInt <$> satisfy isDigit)
>>> [e | (Identity e, "") <- readP_to_S (runJoker (operated [[plus]] digit)) "1+2+3"]
[Plus (Plus (Digit 1) (Digit 2)) (Digit 3)]
