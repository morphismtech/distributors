Prismoid

type Prismoid s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Alternator p, Applicative f) => p a (f b) -> p s (f t) Source #

Prismoids generalize Prisms & Diopters, combining them, matching partially forwards, into a Homogeneous shape, & building totally backwards.

Prism ∪ Diopter ⊂ Prismoid ⊂ Bifocal.

A Prismoid fails by its Alternator, never by its Applicative f, so a Prism, as a Prismoid, fails on a mismatch, rather than passing it through, by the laws of CocartesianChoice, as rebuilding it from its partial functions, by withPartialIso & partialIso, makes it do in any Choice. A Bifocal adds failing backwards, by a Filterable f.

Prismoids are isomorphic to Prismatoids, by Homogeneous shapes, & to Prismoculars, by partial probes.

type APrismoid s t a b = Prismatoid a b a (Identity b) -> Prismatoid a b s (Identity t) Source #

APrismoid is monomorphically a Prismoid.

prop> Prismoid s t a b ⊂ APrismoid s t a b

data Prismatoid a b s t where Source #

A Prismatoid provides efficient access to the pair of functions that make up a Prismoid, like a Dioptrice which may fail to match.

Applicators

(>?*) :: Alternator p => Prismoid s t a b -> p a b -> p s t infixl 4 Source #

Action of a Prismoid on Alternators, applying it directly at the Alternator, without converting it to a concrete form, so the Alternator's own methods, like someP & optionP, act as they are.

prop> prsm >?* p = prsm >? p
prop> atLeast 1 >?* p = someP p
prop> opted def >?* p = optionP def p

So a Prismoid acts on an Alternative, by Joker, as a homomorphism, atLeast 1 to some, several to many, & opted to optional; & on a KleeneStarAlgebra, by Data.Profunctor.Grammar.Grammor, atLeast 1 to plusK, several to starK & opted to optK.

>>> let digits = runJoker (atLeast 1 >?* Joker (satisfy isDigit)) :: ReadP String
>>> [ds | (ds, "") <- readP_to_S digits "123"]
["123"]

sepBy :: Alternator p => p () () -> Prismoid s t a b -> p a b -> p s t Source #

Action of a Prismoid on Alternators, like >?*, with a separator between consecutive foci, data-free, so a shape of n foci gets n - 1 separators, like intersperse. Delimiters compose around it, beg >* sepBy sep pat p *< end. It applies the Prismoid directly, as >?* does, so the Alternator's own manyP, someP, optionalP & optionP sequence the foci, by an upper triangular matrix of actions. It prefers sequencing foci to sequencing none, so a deterministic Alternator sequences them greedily.

prop> sepBy oneP pat p = pat >?* p
prop> sepBy sep (atLeast 1) p = p >:< manyP (sep >* p)
prop> sepBy sep several p = p >:< manyP (sep >* p) <|> asEmpty

Separating several, atLeast, atMost, inRange, chain1, chain or exactly, it sequences lists, binary constructor patterns, or a number of repetitions; & separating a Monocle, like ditraversed, the positions of a fixed product. Other IsLists act as lists by listed ~<.

>>> let comma = Joker (() <$ char ',')
>>> let digit = Joker (satisfy isDigit)
>>> let digits = runJoker (sepBy comma (atLeast 1) digit) :: ReadP String
>>> [ds | (ds, "") <- readP_to_S digits "1,2,3"]
["123"]
>>> let pair = runJoker (sepBy comma ditraversed digit) :: ReadP (Product Identity Identity Char)
>>> [ds | (ds, "") <- readP_to_S pair "1,2"]
[Pair (Identity '1') (Identity '2')]

withOperators Source #

:: Alternator p 
=> [[Operator p a b]]

-> p a b

-> p a b

expression

Build an expression Alternator from a table of Operators and an atomic term Alternator, analogous to buildExpressionParser from parsec.

The operator table is a list of list of operators, ordered from highest to lowest precedence. Each level is a list of Operators which share precedence. Within a level, Infix takes an Assoc to set left, right or non-associativity for binary operators, while Prefix & Postfix are for unary operators.

Its operator symbols are actions of the Alternator p, data-free, so, unlike a Prismoid, it isn't polymorphic in p.

>>> :{
data Sum = Digit Int | Plus Sum Sum deriving Show
_Plus :: Prism' Sum (Sum, Sum)
_Plus = prism' (uncurry Plus) (\case Plus x y -> Just (x, y); _ -> Nothing)
:}

>>> let plus = Infix LeftAssoc _Plus (Joker (() <$ char '+'))
>>> let digit = Joker (Digit . digitToInt <$> satisfy isDigit)
>>> [e | (e, "") <- readP_to_S (runJoker (withOperators [[plus]] digit)) "1+2+3"]
[Plus (Plus (Digit 1) (Digit 2)) (Digit 3)]

For a larger example, see the expression grammar in Control.Lens.Grammar, of natural numbers with postfix, right-associative & left-associative operators.

atLeast :: Int -> Prismoid [a] [b] a b Source #

At least some number of times, or separated by sepBy, ending with the Alternator's own someP, or, for at least none, its own manyP.

prop> atLeast n = inRange n Nothing
prop> atLeast 0 = several
prop> atLeast 1 >?* p = someP p
>>> let digits n = runJoker (atLeast n >?* Joker (satisfy isDigit)) :: ReadP String
>>> [ds | (ds, "") <- readP_to_S (digits 2) "123"]
["123"]
>>> [ds | (ds, "") <- readP_to_S (digits 2) "1"]
[]

inRange :: Int -> Maybe Int -> Prismoid [a] [b] a b Source #

Between some numbers of times, inclusive, at least a lower bound, & at most an upper bound, if there's one, like a regular expression's {lo,hi}, or {lo,}, or separated by sepBy. It takes the mandatory times first, then, unbounded, the Alternator's own someP or manyP, or, bounded, the optional times, trying more first. It never matches where lo > hi.

>>> let digits lo hi = runJoker (inRange lo hi >?* Joker (satisfy isDigit)) :: ReadP String
>>> [ds | (ds, "") <- readP_to_S (digits 2 (Just 3)) "123"]
["123"]
>>> [ds | n <- [1 .. 4], (ds, "") <- readP_to_S (digits 2 (Just 3)) (take n "1234")]
["12","123"]
