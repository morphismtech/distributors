Description

Prisms & Isos of constructors' fields as right-nested pairs, for pattern bonding, generated by Template Haskell, with makeNestedPrisms, or by Generics, with genericNestedPrism & genericNestedIso.

makeNestedPrisms's code is duplicated from PrismTH, with small tweaks to support nested pairs.

Nested prisms

makeNestedPrisms :: Name -> DecsQ Source #

Similar to makePrisms, makeNestedPrisms generates a Prism for each constructor of a data type. Isos are generated when possible. Reviews are generated for constructors with existentially quantified constructors and GADTs. The difference in makeNestedPrisms is that constructors with n > 2 arguments will use right-nested pairs, rather than a flat n-tuple. This makes them suitable for pattern bonding, by use of the applicator >? to Monoidal idiom notation with >*<, or to Data.Profunctor.Monadic.Do qualified do-notation.

e.g.

data FooBar a
  = Foo a
  | Bar Int
  | Baz Int Char
  | Buzz Double String Bool
  | Boop
makeNestedPrisms ''FooBar

will create

_Foo :: Prism (FooBar a) (FooBar b) a b
_Bar :: Prism' (FooBar a) Int
_Baz :: Prism' (FooBar a) (Int, Char)
_Buzz :: Prism' (FooBar a) (Double, (String, Bool))
_Boop :: Prism' (FooBar a) ()

genericNestedPrism :: forall s (con :: Symbol) -> (Generic s, GNestedCon con (Rep s)) => Prism' s (ConFocus con (Rep s)) Source #

A Prism of the constructor of a Generic type named by a Symbol, focusing its fields as right-nested pairs, as makeNestedPrisms would generate, without Template Haskell: () for none, the field for one, & (a, (b, ...)) for more. Where the type & a constructor share a name, the type is named by type, with ExplicitNamespaces, as in genericNestedIso.

>>> :set -XDeriveGeneric -XRequiredTypeArguments
>>> import Control.Lens (preview, review)
>>> import GHC.Generics (Generic)
>>> data FooBar = Foo Int | Bar Int Char Bool | Baz deriving (Show, Generic)
>>> preview (genericNestedPrism FooBar "Bar") (Bar 1 'x' True)
Just (1,('x',True))
>>> preview (genericNestedPrism FooBar "Bar") (Foo 1)
Nothing
>>> review (genericNestedPrism FooBar "Baz") ()
Baz

genericNestedIso :: forall s -> (Generic s, GNestedIso (Rep s)) => Iso' s (IsoFocus (Rep s)) Source #

A Iso of the sole constructor of a Generic type, focusing its fields as right-nested pairs, as makeNestedPrisms would generate, without Template Haskell. Where the type & its constructor share a name, as is usual, the type is named by type, with ExplicitNamespaces.

>>> :set -XDeriveGeneric -XRequiredTypeArguments -XExplicitNamespaces
>>> import Control.Lens (view, review)
>>> import GHC.Generics (Generic)
>>> data Point = Point Int Int Int deriving (Show, Generic)
>>> view (genericNestedIso (type Point)) (Point 1 2 3)
(1,(2,3))
>>> review (genericNestedIso (type Point)) (4, (5, 6))
Point 4 5 6
