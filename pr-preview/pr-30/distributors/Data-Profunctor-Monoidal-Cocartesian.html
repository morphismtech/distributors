CocartesianMonoidal

class Profunctor p => CocartesianMonoidal (p :: Type -> Type -> Type) where Source #

A lax CocartesianMonoidal sum Profunctor has zero zeroP and sum >+< lax monoidal structure morphisms, respecting the cocartesian monoidal structure of Void & Either, as Monoidal respects that of () & (,).

Laws:

>>> let lunit = dimap (either absurd id) Right
>>> let runit = dimap (either id absurd) Left
>>> :{
let assoc = dimap
      (either (Left . Left) (either (Left . Right) Right))
      (either (either Left (Right . Left)) (Right . Right))
:}

prop> zeroP >+< p = lunit p
prop> p >+< zeroP = runit p
prop> p >+< q >+< r = assoc ((p >+< q) >+< r)
prop> dimap (f >+< g) (h >+< i) (p >+< q) = dimap f h p >+< dimap g i q

CocartesianChoice

class (CocartesianMonoidal p, Choice p, forall x y. DisjunctiveMonoid (p x y)) => CocartesianChoice (p :: Type -> Type -> Type) where Source #

CocartesianChoice co-extends Choice and CocartesianMonoidal, with DisjunctiveMonoid failure falseP and choice >|<, like Alternative but without requiring Monoidal structure, and the alternate method, which is a lax monoidal structure morphism on sums, with these laws relating them.

prop> left' = alternate . Left
prop> right' = alternate . Right
prop> zeroP = falseP
prop> x >+< y = alternate (Left x) >|< alternate (Right y)

For the case of Functors, the analog of alternate can be defined without any other constraint, but the case of Profunctors turns out to be slightly more complex, necessitating CocartesianChoice.

>>> :{
alternateF :: Functor f => Either (f a) (f b) -> f (Either a b)
alternateF = either (fmap Left) (fmap Right)
:}
