Vectorial

type Vectorial (f :: Type -> Type) = (Homogeneous f, Distributive f) Source #

Vectorial containers are Homogeneous & Distributive, so every value has the same shape, a fixed number of positions, like Identity, Complex, & their products & compositions. So they zip totally, as Homogeneous structures of different shapes can't, & they're sequenced by Monoidal Profunctors alone, vectorially, which homogeneously specializes.

prop> homogeneously = vectorially

vectorially :: (Vectorial f, Monoidal p) => p a b -> p (f a) (f b) Source #

Sequences an action in every position, by ditraverse.

Zip two structures, position by position.

zipWithVectorial :: Vectorial f => (a -> b -> c) -> f a -> f b -> f c Source #

Zip two structures by a function, position by position, which, as their shapes are the same, never fails.

>>> zipWithVectorial (+) (1 :+ 2) (10 :+ 20)
11 :+ 22
