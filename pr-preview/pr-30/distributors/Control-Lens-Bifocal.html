Bifocal

type Bifocal s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Alternator p, Filtrator p, Alternative f, Filterable f) => p a (f b) -> p s (f t) Source #

Bifocals are bidirectional parser optics.

Every one of the following is a Bifocal.

  • Iso
  • Prism
  • Monocle
  • Diopter
  • Prismoid & Filtroid

Bifocals are isomorphic to Binoculars.

type ABifocal s t a b = Binocular a b a (Maybe b) -> Binocular a b s (Maybe t) Source #

ABifocal is monomorphically a Bifocal.
