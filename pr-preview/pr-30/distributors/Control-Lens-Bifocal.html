Bifocal

type Bifocal s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Alternator p, Applicative f, Filterable f) => p a (f b) -> p s (f t) Source #

Bifocals are bidirectional parser optics. Prismoid ∪ PartialIso ⊂ Bifocal,

so every Iso, Prism, filterPrism, Monocle, Comonocle & Diopter is a Bifocal too.

Bifocals are isomorphic to Spectacles, by Homogeneous shapes, & to Binoculars, by partial probes.

type ABifocal s t a b = Spectacle a b a (Maybe b) -> Spectacle a b s (Maybe t) Source #

ABifocal is monomorphically a Bifocal.

prop> Bifocal s t a b ⊂ ABifocal s t a b

data Spectacle a b s t where Source #

Spectacle provides an efficient concrete representation of Bifocals, by Homogeneous shapes, matching partially forwards & building partially backwards, a tPrismatoid which may also fail to build.

crossBifocal :: ABifocal s t a b -> ABifocal u v a b -> Bifocal (s, u) (t, v) a b Source #

Construct a Bifocal on pairs from components, with the same foci.

>>> withSpectacle (crossBifocal _Just _Just) $ \match build -> (match (Just 1, Just 2) >>= build . fmap negate, match (Just 1, Nothing) >>= build)
(Just (Just (-1),Just (-2)),Nothing)

altBifocal :: ABifocal s t a b -> ABifocal u v a b -> Bifocal (Either s u) (Either t v) a b Source #

Construct a Bifocal on Eithers from components, with the same foci.

>>> withSpectacle (altBifocal _Just _Just) $ \match build -> (match (Left (Just 'x')) >>= build . fmap succ, match (Right Nothing) >>= build)
(Just (Left (Just 'y')),Nothing)

orBifocal :: ABifocal s t a b -> ABifocal s t a b -> Bifocal s t a b Source #

Disjoin two Bifocals on the same source, by >|<.

prop> orBifocal x falseOptic = cloneBifocal x
prop> orBifocal falseOptic y = cloneBifocal y
>>> withSpectacle (orBifocal _Left _Right) $ \match build -> (match (Left 'x') >>= build . fmap succ, match (Right 'x') >>= build . fmap succ)
(Just (Left 'y'),Just (Right 'y'))
