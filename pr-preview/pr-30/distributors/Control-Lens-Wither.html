Wither

type Wither s t a b = forall (f :: Type -> Type). Alternative f => (a -> f b) -> s -> f t Source #

Withers extend Traversals by filtering. Writing ⊂ for "every one is a",

Traversal ⊂ Wither,

so every Iso, Lens & Prism is a Wither too.

type AWither s t a b = (a -> Altar a b b) -> s -> Altar a b t Source #

AWither is monomorphically a Wither.

newtype Altar a b t Source #

This is used to characterize Withers.

Clone AWither so that you can reuse the same monomorphically typed Wither for different purposes.

withered :: forall (t :: Type -> Type) a b. Witherable t => Wither (t a) (t b) a b Source #

Construct a Wither for a Witherable, dropping each element whose action fails, by optional.

A Prism passes a mismatch through, so it filters nothing in a Wither. Penner's witherPrism makes it fail instead, by empty, so that withered drops it.

>>> :{
witherPrism
  :: (Choice p, Alternative f)
  => APrism s t a b -> p a (f b) -> p s (f t)
witherPrism prsm = withPrism prsm $ \embed match ->
  dimap match (either (const empty) (fmap embed)) . right'
:}

>>> (withered . witherPrism _Just) (\x -> Just (x + 1)) [Just 1, Nothing, Just 2]
Just [Just 2,Just 3]

With catMaybes (pure Nothing) in place of empty, witherPrism is clonePartialIso, a PartialIso, for a Filterable f.

>>> (withered . clonePartialIso _Just) (\x -> Just (x + 1)) [Just 1, Nothing, Just 2]
Just [Just 2,Just 3]
