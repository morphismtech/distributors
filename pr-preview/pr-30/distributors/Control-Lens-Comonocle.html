Comonocle

type Comonocle s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (CocartesianMonoidal p, Functor f) => p a (f b) -> p s (f t) Source #

Comonocles are an optic dual to Monocles, by sums, which focus on the one copy that an Enumerable sum holds.

Every Iso is a Comonocle, & every Comonocle is a Lens, whose residue is which copy is held.

>>> view _Enumerable (Identity 'a')
'a'

Comonocles are isomorphic to Comonoculars.

type AComonocle s t a b = Comonocular a b a (Identity b) -> Comonocular a b s (Identity t) Source #

AComonocle is monomorphically a Comonocle.

altComonocle :: AComonocle s t a b -> AComonocle u v a b -> Comonocle (Either s u) (Either t v) a b Source #

Construct a Comonocle on Eithers from components, with the same foci, since sums of copies add, \(m a + n a = (m+n) a\), as choosing does Lenses.

>>> set (altComonocle id _Enumerable) 'x' (Right (Identity 'y'))
Right (Identity 'x')

crossComonocle :: AComonocle s t a b -> AComonocle u v c d -> Comonocle (s, u) (t, v) (a, c) (b, d) Source #

Construct a Comonocle on pairs from components, since products of sums of copies distribute, \(m a \times n c = (m n) (a \times c)\).

>>> over (crossComonocle _Enumerable id) (\(a, c) -> (a + c, show c)) (Identity 1, 2)
(Identity 3,"2")

indexComonocle :: AComonocle s t a b -> IndexedLens Natural s t a b Source #

The IndexedLens of AComonocle, indexed by which copy is held, numbered from 0, left to right. Numbering diverges past a summand of infinitely many copies.

>>> iview (indexComonocle (altComonocle id id)) (Right 'a' :: Either Char Char)
(1,'a')

countComonocle :: AComonocle s t a b -> Natural Source #

How many copies AComonocle has, like the size of a Bounded Enum. It diverges for infinitely many copies, & takes time linear in their number.

>>> countComonocle (_BoundedEnum @Ordering)
3

zipComonocle :: (Traversable f, Alternative g) => AComonocle s t a b -> (f a -> g b) -> f s -> g t Source #

Zip sources of AComonocle in the positions of a Traversable, when they all hold the same copy, or else empty.

>>> zipComonocle (altComonocle id id) (Just . sum) [Left 1, Left 2, Left 3 :: Either Int Int]
Just (Left 6)
>>> zipComonocle (altComonocle id id) (Just . sum) [Left 1, Right 2 :: Either Int Int]
Nothing

zipWithComonocle :: AComonocle s t a b -> (a -> a -> b) -> s -> s -> Maybe t Source #

Zip two sources of AComonocle, when they hold the same copy, dual to cotraverseOf, which zips every Monocle.

>>> zipWithComonocle (altComonocle id id) (+) (Left 1) (Left 2 :: Either Int Int)
Just (Left 3)
>>> zipWithComonocle (altComonocle id id) (+) (Left 1) (Right 2 :: Either Int Int)
Nothing
