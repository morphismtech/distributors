A class of Homogeneous countable sums of countable products.

homogeneously :: Distributor p => p a b -> p (t a) (t b) Source #

Sequences actions homogeneously.

prop> homogeneously @Maybe = optionalP
prop> homogeneously @[] = manyP

Any Traversable & Distributive countable product can be given a default implementation for the homogeneously method with ditraverse.

prop> homogeneously = ditraverse

And any user-defined homogeneous algebraic datatype has a default instance for Homogeneous, by deriving Generic1.

default homogeneously :: (Generic1 t, Homogeneous (Rep1 t), Distributor p) => p a b -> p (t a) (t b) Source #

(Enum e, Bounded e) => Homogeneous ((,) e) Source #

A copy tagged by a finite enumeration is a copy for each tag, numbered by its tag's fromEnum, from minBound, & summed in a balanced tree, built lazily.

>>> map fromEnumerable [(False, 'a'), (True, 'b')]
[0,1]
>>> map fromEnumerable [(LT, 'a'), (EQ, 'b'), (GT, 'c')]
[0,1,2]
>>> zipWithHomogeneous (+) (True, 1) (True, 2 :: Int)
Just (True,3)
>>> zipWithHomogeneous (+) (True, 1) (False, 2 :: Int)
Nothing

Reaching a copy takes time logarithmic in the number of tags, but counting them, as fromEnumerable does, takes time linear in it, so it never ends for Int, & tags whose fromEnum fails, like large Words, aren't enumerable.

zipHomogeneous :: (Homogeneous t, Traversable f, Alternative g) => (f a -> g b) -> f (t a) -> g (t b) Source #

Zip Homogeneous structures in the positions of a Traversable, by a function of their elements at each position, when they have the same shape, or else empty.

>>> zipHomogeneous (Just . sum) [[1, 2], [3, 4], [5, 6 :: Int]]
Just [9,12]
>>> zipHomogeneous (Just . sum) [[1, 2], [3 :: Int]]
Nothing
>>> zipHomogeneous id [[1, 2], [3, 4 :: Int]]
[[1,2],[1,4],[3,2],[3,4]]

zipWithHomogeneous :: Homogeneous t => (a -> a -> b) -> t a -> t a -> Maybe (t b) Source #

Zip two Homogeneous structures, when they have the same shape.

>>> zipWithHomogeneous (+) [1, 2] [3, 4 :: Int]
Just [4,6]
>>> zipWithHomogeneous (+) [1] [3, 4 :: Int]
Nothing

zipWithHomogeneous3 :: Homogeneous t => (a -> a -> a -> b) -> t a -> t a -> t a -> Maybe (t b) Source #

Zip three Homogeneous structures, when they have the same shape.

>>> zipWithHomogeneous3 (\a b c -> a + b + c) [1, 2] [3, 4] [5, 6 :: Int]
Just [9,12]
>>> zipWithHomogeneous3 (\a b c -> a + b + c) [1, 2] [3, 4] [5 :: Int]
Nothing

zipWithHomogeneousM :: (Homogeneous t, Applicative m) => (a -> a -> m b) -> t a -> t a -> m (Maybe (t b)) Source #

Zip two Homogeneous structures by an action, when they have the same shape. The actions of the positions which match run, even when the shapes differ elsewhere.

>>> zipWithHomogeneousM (\a b -> ([a + b], a * b)) [1, 2] [3, 4 :: Int]
([4,6],Just [3,8])
>>> zipWithHomogeneousM (\a b -> ([a + b], a * b)) [1, 2] [3 :: Int]
([4],Nothing)

transposeHomogeneous :: (Homogeneous t, Traversable f) => f (t a) -> Maybe (t (f a)) Source #

Transpose Homogeneous structures in the positions of a Traversable, when they have the same shape. Without any structures, a sum's first copy repeats, so that a list is infinite.

>>> transposeHomogeneous [[1, 2, 3], [4, 5, 6 :: Int]]
Just [[1,4],[2,5],[3,6]]
>>> transposeHomogeneous [[1, 2], [3 :: Int]]
Nothing

Enumerable

class Homogeneous f => Enumerable (f :: Type -> Type) where Source #

A class of Enumerable countable sums of single copies, which are Homogeneous, & sequenced by sums alone.

prop> enumerably @Identity = dimap runIdentity Identity

Every Enumerable is sequenced enumerably as it's sequenced homogeneously, by a Distributor.

prop> enumerably = homogeneously

And any user-defined enumerable algebraic datatype has a default instance for Enumerable, by deriving Generic1.

fromEnumerable :: Enumerable f => f a -> Natural Source #

Which copy an Enumerable sum holds, numbered from 0, left to right, like fromEnum.

>>> fromEnumerable (GT, 'x')
2

toEnumerable :: Enumerable f => a -> Natural -> Maybe (f a) Source #

The copy of an Enumerable sum at an index, if there is one, like toEnum, the inverse of fromEnumerable.

>>> [toEnumerable 'x' i | i <- [0..3]] :: [Maybe (Ordering, Char)]
[Just (LT,'x'),Just (EQ,'x'),Just (GT,'x'),Nothing]

succEnumerable :: Enumerable f => f a -> Maybe (f a) Source #

The next copy of an Enumerable sum, if there is one, like succ.

predEnumerable :: Enumerable f => f a -> Maybe (f a) Source #
