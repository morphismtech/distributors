Data.Profunctor.Monadic.Do

Description

Qualified do-notation for Monadic profunctors, with pattern bonding, to import qualified.

>>> :set -XQualifiedDo
>>> import qualified Data.Profunctor.Monadic.Do as P

See Control.Lens.Grammar for an example of how to use qualified do-notation with pattern bonding.
