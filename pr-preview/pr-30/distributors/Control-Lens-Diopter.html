Diopter

type Diopter s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Distributor p, Applicative f) => p a (f b) -> p s (f t) Source #

Diopters are an optic that generalizes Bifocals and Traversals.

Every Iso and Monocle is a Diopter.

Diopters are isomorphic to Dioptrices.

type ADiopter s t a b = Dioptrice a b a (Identity b) -> Dioptrice a b s (Identity t) Source #

ADiopter is monomorphically a Diopter.

zipDiopter :: (Traversable f, Alternative g) => ADiopter s t a b -> (f a -> g b) -> f s -> g t Source #

Zip sources of ADiopter in the positions of a Traversable, when they have the same shape, or else empty.

>>> zipDiopter manied (Just . sum) [[1, 2], [3, 4], [5, 6 :: Int]]
Just [9,12]
>>> zipDiopter manied (Just . sum) [[1, 2], [3 :: Int]]
Nothing

zipWithDiopter :: ADiopter s t a b -> (a -> a -> b) -> s -> s -> Maybe t Source #

Zip two sources of ADiopter, when they have the same shape.

>>> zipWithDiopter optioned (+) (Just 1) (Just 2 :: Maybe Int)
Just (Just 3)
>>> zipWithDiopter optioned (+) (Just 1) (Nothing :: Maybe Int)
Nothing

transposeDiopter :: Traversable f => ADiopter s t a (f a) -> f s -> Maybe t Source #

Transpose sources of ADiopter in the positions of a Traversable, when they have the same shape.
