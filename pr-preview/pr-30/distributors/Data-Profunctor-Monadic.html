MonadicTrans

class (forall (m :: Type -> Type) x. Monad m => Monad (p m x)) => MonadicTrans (p :: (Type -> Type) -> Type -> Type -> Type) where Source #

A MonadicTrans profunctor transforms a monad m, like a MonadTrans, so that its actions may run effects of m forwards, by liftP, & absorb them backwards, by joinP.

liftP is a monad morphism.

prop> liftP . pure = pure
prop> liftP (m >>= k) = liftP m >>= liftP . k
prop> joinP (fmap pure p) = p
prop> joinP = join . fmap liftP

Minimal complete definition

liftP | joinP
