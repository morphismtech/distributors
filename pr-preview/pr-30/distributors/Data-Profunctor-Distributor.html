Distributor

class (Monoidal p, CocartesianMonoidal p) => Distributor (p :: Type -> Type -> Type) where Source #

A Distributor, or lax distributive profunctor, respects distributive category structure, that is nilary and binary products and coproducts, (), (,), Void and Either, being both Monoidal and CocartesianMonoidal.

Distributor additionally has methods manyP & optionalP, distributing an action over [] and Maybe datatypes, which generalize to homogeneously distributing an action over Homogeneous sum-of-products datatypes.

Alternator

class (Distributor p, CocartesianChoice p, forall x. Alternative (p x)) => Alternator (p :: Type -> Type -> Type) where Source #

The Alternator class co-extends CocartesianChoice and Distributor, as well as Alternative, adding methods someP & optionP, with these laws relating them.

prop> manyP p = optionP _Empty (someP p)
prop> optionalP p = optionP _Nothing (_Just >? p)
prop> someP p = p >:< manyP p

Its Alternative structure agrees with its Alternator structure, many & some repeating an input for manyP & someP.

prop> empty = falseP
prop> (<|>) = (>|<)
prop> many = lmap repeat . manyP
prop> some = lmap repeat . someP

Not all Distributors are Alternators, in particular (->) is a Distributor but cannot be Alternative, because there is no general polymorphic function empty :: a -> b, so (->) isn't an Alternator.
