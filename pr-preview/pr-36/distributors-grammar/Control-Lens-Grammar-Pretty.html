Description

Grammars which lay themselves out, by the layout combinators of Wadler, A prettier printer, printing a Doc of the prettyprinter package, which chooses, by the page's width, between their flat & broken layouts, & parsing every layout they print, with any indentation.

class LaidOut p where Source #

Grammars laid out by Wadler-Leijen layout combinators, choosing between flat & broken layouts.

prop> nestP 0 = id
prop> nestP i . nestP j = nestP (i + j)
