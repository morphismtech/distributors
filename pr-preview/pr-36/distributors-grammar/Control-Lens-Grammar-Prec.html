Description

Grammars of Haskell types, equivalent to their stock Read & Show instances, by precedence, as ReadPrec reads, & showsPrec shows: PrecGrammars, run by PrecGrammaticals, like tPrecedence, which readsPrecG & showsPrecG run.

class (Grammatical Char p, forall x y. (x ~ (), y ~ ()) => IsString (p x y)) => PrecGrammatical (p :: Type -> Type -> Type) where Source #

Grammatical interpreters of precedence, as ReadPrec has, where a grammar runs in a precedence context, from 0 to 11, as showsPrec's is.

Methods

precP :: Int -> p a b -> p a b Source #

At a precedence, failing in a context above it, as prec does.

stepP :: p a b -> p a b Source #

In a context one higher, for arguments, as step does.

resetP :: p a b -> p a b Source #

In the context 0, within brackets, as reset does.

precedenceP :: (Int -> p a b) -> p a b Source #

By the context's precedence.
