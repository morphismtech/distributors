Monocle

type Monocle s t a b = forall (p :: Type -> Type -> Type) (f :: Type -> Type). (Monoidal p, Applicative f) => p a (f b) -> p s (f t) Source #

Monocles are an optic which is both a Traversal & a Grate, focusing on a number of foci fixed by the optic, not its source. Iso ⊂ Monocle ⊂ Traversal ∩ Grate.

Monocles are isomorphic to Monoculars, & those of finitely many foci to Ditraversals, whose shapes are Traversable ∩ Distributive, the shapes of Traversals ∩ the shapes of Grates.

type AMonocle s t a b = Monocular a b a (Identity b) -> Monocular a b s (Identity t) Source #

AMonocle is monomorphically a Monocle.

prop> Monocle s t a b ⊂ AMonocle s t a b

newtype Monocular a b s t Source #

Monocular provides an efficient concrete representation of Monocles.

data Ditraversal a b s t where Source #

Ditraversal is a secondary concrete representation of Monocles, by homogeneous products: a Traversable & Distributive shape, into which a source splits its foci, & from which a target merges them.

Monocles with finitely many foci are isomorphic to Ditraversals, by ditraversal & withDitraversal.

Build a Monocle from a Ditraversal.

>>> over (ditraversal (Ditraversal (uncurry (:+)) (\(x :+ y) -> (x, y)))) negate (1, 2)
(-1,-2)

withDitraversal :: AMonocle s t a b -> (forall (f :: Type -> Type). (Distributive f, Traversable f) => (s -> f a) -> (f b -> t) -> r) -> r Source #

Convert AMonocle to the pair of functions that characterize it, splitting into & merging from a homogeneous product of its foci. It diverges for infinitely many foci, like those of forevered.

>>> withDitraversal (crossMonocle id ditraversed) $ \split _ -> toList (split (1, 2 :+ 3))
[1,2,3]
>>> withDitraversal ditraversed (\split merge -> merge (negate <$> split (1 :+ 2))) :: Complex Int
(-1) :+ (-2)

(-1,(-2) :+ (-3))

Zip with AMonocle, by running it on the Monoidal Profunctor of functions f a -> g b, generalizing both traverseOf, at Identity f, & cotraverseOf, at Identity g.

fociMonocle :: AMonocle s s a a -> [ReifiedLens' s a] Source #

The Lenses of the foci of AMonocle, numbered from 0, left to right, every one of which focuses on a source.

Dual to copiesComonocle: a product of foci has a Lens for each focus, every one of which focuses, as a sum of copies has a Prism for each copy, exactly one of which matches.

>>> [view (runLens focus) (1 :+ 2) | focus <- fociMonocle ditraversed] :: [Int]
[1,2]
>>> [set (runLens focus) 0 (1 :+ 2) | focus <- fociMonocle ditraversed] :: [Complex Int]
[0 :+ 2,1 :+ 0]
